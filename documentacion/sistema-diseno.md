# Sistema de diseño

## Identidad

- Estilo: moderno y profesional.
- Color principal: morado.
- Apariencia: clara.
- Tipografía: Segoe UI con alternativas del sistema.

## Colores

- Principal: #6D28D9
- Acción: #7C3AED
- Fondo: #F8FAFC
- Superficie: #FFFFFF
- Texto: #1E293B
- Texto secundario: #64748B
- Borde: #E2E8F0

## Componentes

- Botones redondeados.
- Tarjetas con bordes sutiles.
- Formularios con etiquetas superiores.
- Tablas con encabezados diferenciados.
- Navegación lateral oscura.

## Reglas

- Mantener consistencia entre módulos.
- Priorizar legibilidad.
- Evitar elementos decorativos innecesarios.
- Utilizar los colores de estado de forma uniforme.
- Diseñar para pantallas de escritorio.
- No depender de internet para cargar fuentes o recursos.
